# Boss artwork

Original transparent PNG illustrations generated for Lifelikegame, using the
approved adventurer mascot as a style reference. These assets ship with the app;
there are no third-party image URLs or runtime image-generation requests.

| Backend key | Character |
| --- | --- |
| slime | 软糖史莱姆 |
| cloud | 困困云怪 |
| mushroom | 蘑菇守卫 |
| pillow | 抱枕巨兽 |
| stone | 小石头人 |
| dragon | 皇冠小龙 |

Artwork lookup is in `src/features/adventure/art.tsx`. HP, names, round and status
come from the backend progress response, not this asset directory.
